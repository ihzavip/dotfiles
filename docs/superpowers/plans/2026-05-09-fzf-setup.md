### Task 1: Add fzf integration to .zshrc

**Files:**
- Modify: `dotfiles/zsh/.zshrc`

The fzf Arch package ships shell integration at `/usr/share/fzf/`. Sourcing those two files activates:
- `Ctrl+R` — fuzzy history search
- `Ctrl+T` — fuzzy file picker (pastes selected path into command line)
- `Alt+C` — fuzzy cd into a subdirectory

- [ ] **Step 1: Verify integration files exist**

```bash
ls /usr/share/fzf/
```

Expected output includes `key-bindings.zsh` and `completion.zsh`.

- [ ] **Step 2: Add fzf block to .zshrc**

Open `dotfiles/zsh/.zshrc`. Append the following block at the end of the file (after the last `source` line, before EOF):

```zsh
# ================================
# fzf
# ================================
# Shell integration (Ctrl+R, Ctrl+T, Alt+C)
source /usr/share/fzf/key-bindings.zsh
source /usr/share/fzf/completion.zsh

# Use fd as the default find backend (faster, respects .gitignore)
export FZF_DEFAULT_COMMAND='fd --type f --hidden --follow --exclude .git'
export FZF_CTRL_T_COMMAND="$FZF_DEFAULT_COMMAND"
export FZF_ALT_C_COMMAND='fd --type d --hidden --follow --exclude .git'

# Appearance: gruvbox dark + preview window (toggle with Ctrl+/)
export FZF_DEFAULT_OPTS="
  --height 40%
  --border rounded
  --layout reverse
  --prompt '❯ '
  --color=bg+:#3c3836,bg:#282828,spinner:#fb4934,hl:#928374
  --color=fg:#ebdbb2,header:#928374,info:#8ec07c,pointer:#fb4934
  --color=marker:#fb4934,fg+:#ebdbb2,prompt:#fb4934,hl+:#fb4934
  --preview 'cat {}'
  --preview-window right:50%:hidden
  --bind 'ctrl-/:toggle-preview'
"
```

Note: `--preview 'cat {}'` gives a plain file preview. If `bat` is installed later (`sudo pacman -S bat`), swap it for `'bat --style=numbers --color=always --line-range :500 {}'` for syntax-highlighted previews.

- [ ] **Step 3: Reload zsh config**

```bash
source ~/.zshrc
```

- [ ] **Step 4: Verify Ctrl+R works**

Press `Ctrl+R` in the terminal. Expected: fzf opens in the bottom 40% of the terminal showing command history in gruvbox colours. Type to fuzzy-filter; Enter to select.

- [ ] **Step 5: Verify Ctrl+T works**

Type `cat ` (with a space), then press `Ctrl+T`. Expected: fzf opens showing files under the current directory (found by `fd`). Select one; its path is appended to the command line.

- [ ] **Step 6: Verify Alt+C works**

Press `Alt+C`. Expected: fzf opens showing subdirectories. Select one; the shell cds into it.

- [ ] **Step 7: Commit**

```bash
cd /home/lucy/dotfiles
git add zsh/.zshrc
git commit -m "feat: add fzf shell integration with fd backend and gruvbox theme"
```
